Millet Vista · RAG API

Knowledge backend

This service powers the AI chatbot inside your Millet Vista website. It receives PDF uploads, embeds them with Gemini and answers questions on demand.

Endpoints
GET /api/health  — service status, embedded chunk count, configured models
GET /api/documents  — list ingested PDFs (public)
POST /api/upload  — upload PDFs (multipart files) — admin only
DELETE /api/documents/:id  — remove a doc — admin only
POST /api/chat  — streamed RAG answer (SSE)
POST /api/chat/sync  — non-streaming variant
